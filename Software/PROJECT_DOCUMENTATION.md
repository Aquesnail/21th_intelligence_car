# 第21届智能车竞赛 - 软件系统文档

## 项目概述

### 项目简介
本项目是为第21届全国大学生智能汽车竞赛开发的嵌入式软件系统，基于**STC32G144K246**微控制器（8051架构，C251核心）构建。系统采用**FreeRTOS**实时操作系统，实现了模块化、可扩展的软件架构，为智能车的运动控制、姿态感知、调试监控等功能提供完整支持。

### 主要特性
- **实时多任务系统**：基于FreeRTOS，支持优先级调度、任务通信、时间片轮转
- **高性能姿态感知**：集成ICM42688 6轴IMU，500Hz采样率，Mahony互补滤波算法
- **高级调试系统**：支持变量实时监控、日志输出、远程命令执行
- **模块化外设驱动**：SPI DMA、I2C、PWM、UART DMA等高效驱动
- **参数存储**：预留Flash接口，支持校准数据、控制参数固化（开发中）
- **丰富的外设支持**：蜂鸣器、WS2812 LED、按键、系统状态监控

### 技术栈
- **微控制器**：STC32G144K246（120MHz主频，32位C251核心）
- **实时操作系统**：FreeRTOS v202112.00
- **开发环境**：Keil uVision（MCS-251工具链）
- **编程语言**：C语言（C251兼容）
- **调试工具**：Python上位机（up.py），支持数据可视化

### 项目状态
- **当前版本**：V1.0（开发中）
- **代码规模**：188个源文件（.c/.h）
- **架构成熟度**：中等偏上（评分3.6/5.0）
- **测试覆盖**：基础功能测试完备，核心算法测试待加强

#### 外设配置详情
1. **SPI2配置**
   - 模式：Mode 3 (CPOL=1, CPHA=1)
   - 时钟分频：主频/16（7.5MHz @120MHz）
   - 数据顺序：MSB优先
   - DMA支持：发送/接收双缓冲

2. **UART5配置**
   - 波特率：115200 bps
   - 数据位：8位
   - 停止位：1位
   - 校验位：无
   - DMA模式：环形缓冲区管理

3. **PWM配置**
   - PWMA：通道3、4用于蜂鸣器
   - PWME：通道5用于WS2812时序生成
   - 时钟源：系统时钟120MHz
   - 分辨率：16位（1-65535）

4. **系统时钟**
   - 主时钟：120MHz（外部晶振+PLL）
   - 内部高速IRC：48MHz（备用）
   - FreeRTOS Tick：1kHz（1ms周期）

### 传感器规格
#### ICM42688 6轴IMU
- **加速度计**：±16g量程，500Hz ODR
- **陀螺仪**：±2000dps量程，500Hz ODR
- **温度传感器**：内置
- **FIFO**：2048字节，支持批量读取
- **通信接口**：SPI 10MHz（最大）

#### 其他传感器（规划中）
- 电机编码器：正交编码接口（QEI）
- 超声波/红外测距：ADC采集
- 摄像头接口：并口/DVP接口

### 电源设计
- **供电电压**：3.3V（LDO稳压）
- **电流容量**：峰值2A（电机驱动时）
- **低功耗模式**：支持睡眠/停机（未实现）
- **电压监控**：LVR 2.0V阈值，欠压自动复位

### 内存映射
| 内存区域 | 地址范围 | 大小 | 用途 |
|---------|---------|------|------|
| **CODE** | 0xFC2800-0xFFFFFF | 246KB | 程序代码 |
| **IRAM** | 0x0000-0x3FFF | 16KB | 内部RAM（堆栈、快速变量） |
| **XRAM** | 0x10000-0x2FFFF | 128KB | 外部RAM（大数据缓冲区） |
| **SFR** | 0x8000-0xFFFF | 32KB | 特殊功能寄存器 |

### FreeRTOS配置
| 配置项 | 值 | 说明 |
|--------|-----|------|
| 调度策略 | 抢占式+时间片 | configUSE_PREEMPTION=1, configUSE_TIME_SLICING=1 |
| Tick频率 | 1000Hz | configTICK_RATE_HZ=1000 |
| 最大优先级 | 32 | configMAX_PRIORITIES=32 |
| 最小堆栈 | 256字节 | configMINIMAL_STACK_SIZE=256 |
| 堆大小 | 8KB | configTOTAL_HEAP_SIZE=8192 |
| 任务通知 | 启用 | configUSE_TASK_NOTIFICATIONS=1 |
| 互斥锁 | 启用 | configUSE_MUTEXES=1 |
| 软件定时器 | 启用 | configUSE_TIMERS=1 |
| 栈溢出检查 | 级别2 | configCHECK_FOR_STACK_OVERFLOW=2 |
